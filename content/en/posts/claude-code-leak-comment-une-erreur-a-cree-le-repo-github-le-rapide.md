## Executive Summary

On March 2026, Anthropic inadvertently exposed over 500,000 lines of TypeScript source code through a leaked npm package map file. This packaging error triggered an unprecedented open-source response: developer Sigrid Jin engineered Claw Code, a high-performance Rust rewrite, which accumulated 105,000 GitHub stars within 24 hours—establishing a record for repository growth velocity. The incident exposed architectural details of Claude Code's agent loop, tool system, and permission models, while revealing internal exploration of autonomous background agents (KAIROS) and undercover contribution modes. Anthropic subsequently filed over 8,000 copyright claims. The event created a significant intersection of intellectual property rights, software supply chain security, and AI governance—raising questions about source code protection, the viability of copyright enforcement in AI-generated code scenarios, and architectural transparency as a security liability.

## Key Points

- **Leak Vector**: Source code exposure occurred via a source map file (.map) accidentally published in npm registry, enabling full TypeScript reconstruction and rapid analysis of Claude Code's internal architecture.

- **Claw Code Response Timeline**: Within 24 hours of the leak's discovery, Sigrid Jin released a functionally equivalent Rust-based alternative that achieved the fastest GitHub star acquisition rate on record (105,000 stars/day).

- **Architectural Disclosure**: Leaked materials revealed Claude Code's agent loop mechanics, tool system design, permission model framework, and experimental autonomous agent systems (KAIROS protocol), reducing Anthropic's technical differentiation.

- **Legal Response Scale**: Anthropic issued 8,000+ copyright takedown notices, though the efficacy of copyright claims remains contested—particularly when applied to AI-generated or AI-rewritten code derivatives.

- **Governance Conflict**: The incident exposes a paradox in AI copyright law: leaked open-source recreations of proprietary AI tooling operate in a regulatory vacuum where attribution, derivation, and reusability rights remain legally ambiguous.

- **Supply Chain Implications**: The speed of code reconstruction highlights a critical DevOps risk: once architectural patterns are disclosed, competing reimplementations can achieve feature parity faster than legal remediation cycles.
