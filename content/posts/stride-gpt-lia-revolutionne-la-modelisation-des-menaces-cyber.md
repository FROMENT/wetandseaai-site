## Contexte

**STRIDE GPT** is an automated security tool designed to streamline **threat modeling** by utilizing advanced **large language
models**. This open-source application analyzes software details or architecture diagrams to identify vulnerabilities based on
the established **STRIDE framework**. Beyond simple threat identification, the system generates visual **attack trees**, 
calculates **DREAD risk scores**, and proposes specific **mitigation strategies**. Users can interact with the tool through a 
web interface, and it supports a wide variety of AI providers including **OpenAI**, **Google Gemini**, and locally hosted 
models. The project also features capabilities for **GitHub repository analysis**, allowing developers to automatically assess
their codebases for security flaws. Developed by **Matt Adams**, the tool is available as a **Python** application or a 
**Docker** container for flexible deployment.
